## Запуск

API уже должен работать. Если он не запущен, в одном терминале:

```bash
make run-api
```

По последнему решению автора API выдаёт JWT. Логин, пароль и пункты меню не менялись.
После обновления сервера нужно выйти из TUI и войти заново, чтобы получить новый токен.

В другом терминале из `C:/ATAP`:

```bash
make run
```

Либо запускать проверенную сборку:

```text
C:\ATAP\ATAP.ConsoleUI\bin\Release\net8.0\ATAP.exe
```

## Сценарий 1. Вход, аналитика и новое сохранение

Каждый ввод заканчивается Enter. После сообщения «Нажмите Enter для продолжения»
сначала нажать Enter, затем выбирать следующий пункт меню.

| Шаг | Ввод | Результат |
|---|---|---|
| 1 | В гостевом меню `1` | Форма входа |
| 2 | Логин `demo_analyst_lr3`, пароль `Demo#2026` | «Добро пожаловать… Роль: analyst» |
| 3 | Enter, затем `2` | Анализ загруженности |
| 4 | ID `4` | Выбран нужный аэропорт |
| 5 | Начало `2026-06-10` | Начальная дата |
| 6 | Конец `2026-06-10` | Таблица аналитики, счётчики 0/0, сообщение об успешном формировании |
| 7 | Enter, затем `6` | Сохранение отчёта |
| 8 | Название `LR3 Bellona defense` | Имя сохраняемого набора параметров |
| 9 | Начало `2026-06-10`, конец `2026-06-10` | «Отчёт … сохранён» |
| 10 | Enter, затем `7` | Список «Мои сохранённые отчёты» |
| 11 | ID строки с названием `LR3 Bellona defense` | Сохранённый отчёт открыт |

ID нового отчёта выдаёт PostgreSQL; его нужно взять из напечатанного списка.
Не подставлять заранее предполагаемое следующее число.

Для преподавателя:

> «Вход выполняется через API. Затем TUI запрашивает аналитику по аэропорту и периоду.
> Я сохраняю название и параметры отчёта в БД. При открытии отчёта аналитика повторно
> запрашивается по сохранённым параметрам».

## Сценарий 2. Проверить сохранение после выхода

1. На экране открытого отчёта нажать Enter.
2. В меню аналитика выбрать `0` — выход из аккаунта.
3. В гостевом меню выбрать `1` и снова войти `demo_analyst_lr3` / `Demo#2026`.
4. Нажать Enter, выбрать `7`.
5. Найти `LR3 Bellona defense` и ввести его ID.

Ожидается тот же сохранённый отчёт с аэропортом Bellona/Anua Airport и периодом
2026-06-10–2026-06-10. Это подтверждает хранение в БД, а не только в памяти TUI.
